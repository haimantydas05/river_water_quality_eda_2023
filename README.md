India River Water Quality Analysis using Python & GeoPandas | 2023

Excited to share my latest data project — an end-to-end EDA on India's river water quality monitoring data for 2023, combining Python data science with geospatial visualization!

 What the project covers:

Data cleaning & preprocessing with Pandas

State-wise analysis of pH, Dissolved Oxygen (DO) & Biochemical Oxygen Demand (BOD)

Bar charts & correlation heatmap across all water quality parameters

Anomaly detection — flagging stations exceeding safe water quality thresholds

Choropleth map of BOD anomalies across Indian states using GeoPandas + Matplotlib

Key findings: Multiple states showed BOD levels exceeding 3 mg/L — a key indicator of organic pollution. DO levels below 5 mg/L at several stations signal serious stress for aquatic ecosystems.

This project reflects how my background in GIS & Remote Sensing shapes the way I approach environmental data — thinking spatially from the start, not as an afterthought.
